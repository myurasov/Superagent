## How this file stays current

- Skills append a new H4 entry whenever they process a touchpoint for this domain.
- Manual entries are welcome — drop them at the top of the Log section in the same `#### YYYY-MM-DD — <title>` format.
- Do not delete entries (history is append-only). Mark superseded findings with `(superseded YYYY-MM-DD: see <newer-entry>)` instead.
- Optional auto-managed blocks delimited by HTML-comment markers `auto:<slug>:start` / `auto:<slug>:end` (e.g. `ingest-events`) may follow the Log. Content between the markers is regenerated by `uv run python -m superagent.tools.render_domain`; hand edits there are clobbered. Opt-in per `contracts/domain-reflection.md` — insert the marker pair to enable, remove it to disable.
