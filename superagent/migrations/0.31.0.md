## Summary

0.31.0 changes who hears what when agents run as sessions of their own. An
agent says which updates it wants to hear about: its interests, handles or
handle globs on its registry row (`agents interest <agent> --add ...`). After
a cycle the Updater tells each agent what moved for it
(`agents interested`), in place of the hardwired hand-offs and of a run
report to the lead. Agents write to each other directly, and the lead hears
only what needs a decision, what the owner must hear before the next
briefing, and an agent's start and end (`contracts/agents.md` § 8a).

A registry row gains the optional list `interests`; a row without it has
none. A role file may name its role's interests in the frontmatter. This
step writes those role interests onto the row of each agent a session holds,
so the Updater has somebody to tell from the first cycle on: without it the
Bookkeeper would hear of no bank harvest until it wrote its own. A workspace
with no agent held by a session gets the version stamp and nothing else.

## Migrate

1. For each agent that `uv run python -m superagent.tools.agents list` shows
   as `active` or `dormant`, leaving out the lead and the Updater, run
   `uv run python -m superagent.tools.agents interest <name> --defaults`
   (`<name>` is the id without its prefix: `bookkeeper`, `project:<slug>`).
   It writes the interests the agent's role file names onto its registry
   row, leaves an interest the agent has already as the agent wrote it, and
   prints what it added. An interest that fires a wake with no grant is
   named and left out: the grant comes first (`contracts/agents.md` § 8).
   With no such agent, skip this step.
2. The `migrate` skill advances `workspace/.version` to `0.31.0` once Validate
   passes.

## Validate

- [ ] `uv run python -m superagent.tools.validate` exits 0.
- [ ] `uv run python -m superagent.tools.agents heartbeat` exits 0, and with

- [ ] Idempotent: running step 1 again prints "the role's interests are

## Revert

1. Optional, while the 0.31.0 tools are still in place: drop the interests
   this step wrote (`uv run python -m superagent.tools.agents interest
   <name> --remove <pattern>`). They may also stay: 0.30.0 ignores the field
   and keeps it when it rewrites a row.
2. Set `workspace/.version` back to `0.30.0`:
   `uv run python -m superagent.tools.version set 0.30.0`. With 0.30.0 the
   Updater's hand-offs are the fixed ones again (the lead, the Bookkeeper
   after a finance harvest, a project agent for a watcher of its project).
