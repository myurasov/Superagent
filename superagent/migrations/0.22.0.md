## Summary

0.22.0 adds `tools/signals.py` (the one writer for action-signal and
interaction-log rows), `tools/cadence.py` (cadence run markers and the
on-open status check) and wider credential redaction. Nothing in an existing
workspace needs converting: the new `context.yaml.last_runs.<key>_started`
markers are optional and appear on the first `cadence start`, and the new
signal-row checks in `tools/validate.py` only warn. This step advances
`workspace/.version` and nothing else.
