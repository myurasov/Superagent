## Summary

0.14.0 adds the report pipeline — the `report` skill plus
`tools/render_report.py` (agent-authored HTML printed to a US-Letter PDF via
Playwright's Chromium, with page furniture, a lazy-render skip, and a
post-render page guard) and the `templates/reports/` base stylesheet +
scaffold. Everything new is framework-side and lazy: report stylesheets
materialize next to each report source on first render, `Outbox/reports/` is
created on first use per `contracts/outbox-lifecycle.md`, and an optional
user theme is honored at `workspace/_custom/templates/reports/theme.css`.
No existing workspace file changes shape, moves, or is rewritten.

## Pre-flight checks

- [ ] Workspace exists at the resolved path.
- [ ] `_memory/config.yaml` is well-formed YAML.

## Migrate

1. Advance `workspace/.version` to `0.14.0`.

Optionally (not required, and not done by this migration): install Chromium
for Playwright if it has never been installed on this machine
(`uv run playwright install chromium`) — browserctl users already have it.
The renderer prints this exact command when Chromium is missing.

## Validate

- [ ] `workspace/.version` reads `0.14.0`.
- [ ] `uv run python -m superagent.tools.render_report --help` exits 0.

2. Optionally remove any seeded `report-style.css` / `report-theme.css`
