## Summary

0.16.0 lands approved suggestion st-2026-08-31-010 option (c): the events
stream (`_memory/events/<YYYY-Qn>.yaml`) becomes a DERIVED VIEW. No skill
mirrors per-write anymore; `tools/events_derive.py rebuild` regenerates the
partitions wholesale from the two sources of truth (`interaction-log.yaml` +
Domain/Project `history.md` H4 entries), the same way `tools/world.py
rebuild` regenerates the world graph. The hand-curated 2026-Q2 rows are
flagged `legacy: true` and frozen byte-verbatim; the max legacy `ts` becomes
the derivation watermark. Config gains `preferences.events.mode: derived |
off`; the never-implemented `auto_mirror_history_md` /
`auto_mirror_interaction_log` toggles are retired. Rebuild cadence:
weekly-review § 8b (derived views) + a `doctor` staleness check
(`events_derive check`).

## Pre-flight checks

- [ ] Workspace exists at the resolved path.
- [ ] `_memory/config.yaml` is well-formed YAML.
- [ ] If `_memory/events/2026-Q2.yaml` exists, it parses and its `events:`
      list rows each carry an `id` + `ts`.

## Migrate

1. Flag the existing hand-authored 2026-Q2 event rows as frozen legacy rows
   (idempotent; pure line insertion — every existing byte is preserved):
   `uv run python -m superagent.tools.events_derive flag-legacy 2026-Q2`.
   Skip silently if the partition does not exist.
2. Update `_memory/config.yaml` `preferences.events`: add `mode: "derived"`
   and remove (or comment with a `# retired 0.16.0` note) the
   `auto_mirror_history_md` / `auto_mirror_interaction_log` lines. Keep
   `partition` and `skip_kinds` (the latter now filters derivation).
3. Run the first derivation:
   `uv run python -m superagent.tools.events_derive rebuild`.
4. Advance `workspace/.version` to `0.16.0`.

## Revert

1. In `_memory/events/2026-Q2.yaml` (and any other partition holding
   `legacy: true` rows), delete every row that does NOT carry `legacy: true`
   — after the first rebuild, derived rows interleave with the frozen legacy
   rows in the same partition.
2. Remove the inserted `    legacy: true` lines from the surviving rows.
   Each row is now byte-identical to its pre-migration form.
3. Delete any partition files that contain only derived rows (no
   `legacy: true` rows), and the `derive_state` block from
   `_memory/events.yaml`.
4. Restore `_memory/config.yaml` `preferences.events` to
   `auto_mirror_history_md: true` / `auto_mirror_interaction_log: true` and
   drop `mode`.
5. Restore `workspace/.version` to `0.15.0`.

**Revert caveat (rows yes, wrapper no):** the first rebuild replaces a mixed
partition's original header comment block and top-level meta
(`event_count`, `by_kind`, hand-written notes) with the regenerated
`PARTITION_HEADER` + derived meta. Revert restores every event ROW
byte-identical, but the partition's header comments / meta wording are
re-rendered, not byte-original — re-author them by hand if their exact
wording matters.
