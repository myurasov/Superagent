## Summary

0.29.0 adds `browserctl doctor`: a check that Playwright's Chromium is
installed and, on Linux, that its sandbox can start. Ubuntu 23.10 and later
grant unprivileged user namespaces per AppArmor profile, so a browser started
from an unconfined shell could die at launch with `No usable sandbox!`. The
command finds that before an errand and prints the cause, the fix and the
undo; `doctor --install-profile` writes and loads the AppArmor profile, and
runs only after the owner's yes (`skills/browserctl.md` § "Linux").

Nothing in an existing workspace needs converting. This step advances
`workspace/.version` and nothing else. It writes no system file and starts no
browser: the profile is installed by the command alone, on a machine where
the owner approved it.

After the step, on a Linux machine that drives a browser, run
`uv run superagent/tools/browserctl.py doctor` once. It is a check of the
machine and no part of this migration.
