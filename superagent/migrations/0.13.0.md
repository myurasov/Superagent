## Summary

The per-web-app browserctl plugin convention changes from
`workspace/_custom/skills/browserctl-<app>.skill.md` to
`workspace/_custom/skills/browserctl.<app>.md`, matching the portable plugin
shape documented in `skills/browserctl.md` Step 5 so plugins can be exchanged
with other browserctl-based agent installations by rewriting only path
prefixes. Existing plugin files are renamed in place; their contents are not
rewritten. No data is lost and nothing outside `_custom/skills/` is touched.

## Pre-flight checks

- [ ] Workspace exists at the resolved path.
- [ ] `_memory/config.yaml` is well-formed YAML.
- [ ] `workspace/_custom/skills/` exists (skip the whole migration cleanly if
      it does not — a workspace that never drove a web app has nothing to
      rename).
- [ ] No file already exists at a target `browserctl.<app>.md` path that would
      be overwritten by the rename (abort and report the collision).

## Migrate

1. Enumerate `workspace/_custom/skills/browserctl-*.skill.md`. If none, record
   "no plugins to rename" and go to step 3.
2. For each match, rename `browserctl-<app>.skill.md` to `browserctl.<app>.md`
   in place (same directory, contents untouched). `<app>` is the segment
   between the `browserctl-` prefix and the `.skill.md` suffix.
3. Advance `workspace/.version` to `0.13.0`.

Optionally (not required, and not done by this migration): update each renamed
file's frontmatter `name:` from `browserctl-<app>` to `browserctl.<app>` and
re-shape its sections onto the portable spine in `skills/browserctl.md`
Step 5. Plugins keep working without this; it only matters when exchanging a
file with another installation.

## Validate

- [ ] `workspace/_custom/skills/` contains no remaining
      `browserctl-*.skill.md` files.
- [ ] Every plugin that existed before the migration is present under its new
      `browserctl.<app>.md` name, with an unchanged byte count.
- [ ] `workspace/.version` reads `0.13.0`.

## Revert

1. Enumerate `workspace/_custom/skills/browserctl.*.md`.
2. For each match, rename `browserctl.<app>.md` back to
   `browserctl-<app>.skill.md`. Skip any file created after the migration that
   never had a hyphenated predecessor (a plugin authored under the new
   convention has no old name to return to — leave it and report it).
3. Restore `workspace/.version` to `0.12.0`.
