## Summary

0.8.0 prunes framework features that never materialized workspace state and
had no usage or demand after three months: scenarios, play/playbooks,
session-scratchpad, briefing-cache, snapshot-diff, working-set, pm-review,
the decisions skill (the `decisions.yaml` store and contract stay), the
notification-policy store, the orphan `log_summarize.py`, and 13 orphaned
contracts. Workspace-side, two dead seed files are retired: they are
MOVED (not deleted) to `_memory/_retired/`, so revert is a move back.
The events stream (`_memory/events.yaml` partition index plus the
`events/<YYYY-Qn>.yaml` partitions) is a LIVE feature and is untouched.

## Pre-flight checks

- [ ] Workspace exists at the resolved path.
- [ ] `workspace/.version` reads `0.7.0` (or a PATCH above it).

## Migrate

1. Create `workspace/_memory/_retired/` if missing.
2. For each of `working-sets.yaml` and `notification-policy.yaml` under
   `workspace/_memory/`: if the file exists, move it to
   `workspace/_memory/_retired/<name>` (skip silently if absent).
3. If `_memory/config.yaml` contains any of the retired preference blocks
   (`preferences.briefing_cache`, `preferences.session`,
   `preferences.telemetry.record_working_sets`,
   `preferences.privacy.snapshot_memory_daily`,
   `preferences.privacy.snapshot_retention_days`), leave them in place —
   they are inert (read by nothing) and removing user config lines is not
   worth the edit risk. New workspaces no longer get them.
4. Write `0.8.0` to `workspace/.version`.

## Validate

- [ ] `workspace/.version` reads `0.8.0`.
- [ ] Neither retired file remains directly under `_memory/`.
- [ ] `uv run python -m superagent.tools.version check` exits 0.

## Revert

1. Move either file present in `workspace/_memory/_retired/` back to
   `workspace/_memory/`.
2. Write `0.7.0` to `workspace/.version`.
