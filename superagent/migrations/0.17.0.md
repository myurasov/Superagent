## Summary

0.17.0 relocates the inbox triage decision log from `Inbox/_processed.yaml`
to `_memory/inbox-log.yaml`. The log is agent state (one append-only row per
triage decision: the filename as dropped, action, destination, note), so it
belongs with the other time-shape logs under `_memory/` -- next to the
`inbox-rules.yaml` the pattern-learning step writes -- rather than in the
user's drop zone. The move is a plain rename; no row is rewritten. Tooling
(`tools/inbox_triage.py record`, the `inbox-triage` and `add-source` skills)
now reads and writes the new path only, and refuses to write while the legacy
file is still present.

## Pre-flight checks

- [ ] Workspace exists at the resolved path.
- [ ] `_memory/config.yaml` is well-formed YAML.
- [ ] If `Inbox/_processed.yaml` exists, it parses as YAML into a mapping
      with a `decisions` list. Hand-written rows sometimes drift in
      indentation; repair the file by hand before migrating (the tool cannot
      repair it, and once moved the file falls under `tools/validate.py`).
- [ ] `_memory/inbox-log.yaml` does not already exist, unless it is
      byte-identical to `Inbox/_processed.yaml` (interrupted earlier run).

## Migrate

1. If `Inbox/_processed.yaml` exists: note its `decisions` row count, then
   rename it to `_memory/inbox-log.yaml` (plain rename, content untouched).
   If it does not exist there is nothing to move -- the tool creates the new
   file lazily on the first recorded decision.
2. Advance `workspace/.version` to `0.17.0`.

## Validate

- [ ] `Inbox/_processed.yaml` no longer exists.
- [ ] If a file was moved: `_memory/inbox-log.yaml` parses and its
      `decisions` row count equals the pre-move count.
- [ ] `uv run python -m superagent.tools.validate` reports no errors for
      `inbox-log.yaml`.
- [ ] `workspace/.version` reads `0.17.0`.

## Revert

1. If `_memory/inbox-log.yaml` exists, rename it back to
   `Inbox/_processed.yaml` (create `Inbox/` if it is missing). Rows appended
   after the migration travel with it; the pre-0.17.0 tool appends to that
   path normally.
2. Restore `workspace/.version` to `0.16.0`.
