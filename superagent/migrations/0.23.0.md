## Summary

0.23.0 makes the framework run on Linux and under OpenCode, and moves the
agent role files into `superagent/agents/`. Nothing in an existing workspace
needs converting: the changes are framework code, docs and a new committed
config template (`opencode.jsonc.opencode`). This step advances
`workspace/.version` and nothing else.

Two things a user may want to do by hand afterwards, neither required:

- Under OpenCode, copy `opencode.jsonc.opencode` to `opencode.jsonc` and add
  the MCP servers the workspace uses (`init` § 4c does the copy on a re-run).
- An overlay file that cites a role file by its old path
  (`superagent/<name>.agent.md`) should cite `superagent/agents/<name>.agent.md`.
