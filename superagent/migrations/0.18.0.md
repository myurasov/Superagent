## Summary

0.18.0 repairs drift that the 2026-09 hygiene pass found across real
workspaces: `history.md` entries appended at the bottom as `## <date> ...` or
`### <title> -- <date>` headers (invisible to `events_derive`, which only
reads `#### YYYY-MM-DD -- <title>`), `model-context.yaml` `sessions` lists
past the 10-row cap, enabled data sources missing from `config.yaml`, a
missing `Outbox/README.md`, and a stale derived `world.yaml`. Every step is
generic, idempotent, and information-preserving: headers are re-levelled and
re-sequenced with bodies kept verbatim; nothing is deleted except sessions
rows beyond the cap (and those are checkpointed first). Before any file is
rewritten, its original bytes are copied to
`_memory/_checkpoints/0.18.0/<relative path>` so `revert.py` can restore it.
That folder is a migration-scoped checkpoint, not a general snapshot
facility.

## Pre-flight checks

- [ ] Workspace exists at the resolved path.
- [ ] `_memory/config.yaml` is well-formed YAML.
- [ ] `_memory/data-sources.yaml` (if present) parses and its `sources`
      rows carry `id` + `enabled`.
- [ ] `_memory/model-context.yaml` (if present) parses.
- [ ] Nothing under `_memory/_checkpoints/0.18.0/` from an aborted earlier
      attempt that the user wants to keep -- an existing checkpoint file is
      NOT overwritten (the earliest original wins), which is what makes a
      re-run after a halt safe.

## Migrate

All steps are performed by
`uv run python superagent/migrations/0.18.0/migrate.py --workspace <path>`
(add `--dry-run` to report only). The script is authoritative; the
per-step description below is what it does.

1. **history.md header normalization.** For every `Domains/*/history.md`,
   `Projects/*/history.md`, and `Archive/**/history.md`: inside the `## Log`
   section (from the `## Log` heading up to the next `## ` heading that is
   not itself a dated entry, e.g. `## Recent ingest events`, or EOF),
   rewrite every top-level dated entry header to
   `#### YYYY-MM-DD -- <title>` (em-dash separator). Recognized shapes:
   (a) `## <date> -- <title>` / `### <date> -- <title>` (date-led, wrong
   level); (b) `### <title> -- <date>` or `## <title> -- <date>`, optionally
   followed by a parenthetical qualifier such as `(evening)` or a trailing
   word -- the date moves to the front and the qualifier is appended to the
   title; (c) canonical `#### <date> -- <title>` (unchanged, including a
   dash-free time / parenthetical suffix after the date); (d)
   `#### <date> <title>` with no separator (separator inserted). Em-dash,
   en-dash and ` - ` separators are all accepted. Undated `###` sub-headers
   inside an entry stay as body content. Then stable-sort the top-level
   entries newest-first by date (same-date entries keep their relative
   order); each entry's body through its trailing `---` travels with it.
   Everything outside the Log section is preserved byte-for-byte; a
   `_Last updated: ..._` line, if present, is refreshed to today's ISO date
   only when the file changed. The original is checkpointed before the
   write. Per-file summary: `<N> header(s) normalized, reordered: yes|no`.
2. **model-context.yaml sessions cap.** If `sessions` holds more than 10
   rows, keep the 10 newest by their date field (`date`, then `ts`, then
   `at`; list order if no common key) ordered newest-first. Text-level
   edit: comments and every other section are preserved. Checkpointed
   first.
3. **config.yaml source registration.** For every row in
   `_memory/data-sources.yaml` with `enabled: true`, ensure the source
   appears under `data_sources_configured` (grouped mapping per the template
   -- e.g. `finance.simplefin: true`; a `false` value is flipped to `true`;
   an unknown source lands under `other`) and under
   `preferences.ingestion_schedule` (the row's `schedule` value, or
   `"daily"` when it is empty). Minimal line insertions keep comments
   intact; missing parent blocks are created. When (and only when) the
   file changed, top-level `last_updated` is set to now (ISO 8601 with
   timezone). Checkpointed first.
4. **Outbox/README.md.** If `<workspace>/Outbox/README.md` is missing,
   copy `superagent/templates/folder-readmes/Outbox.md` there.
5. **world.yaml rebuild.** Run
   `uv run python -m superagent.tools.world --workspace <path> rebuild`.
   `world.yaml` is a derived view; a failure here is reported as a warning
   and does not halt the migration. (`--skip-world` skips the step.)
6. **transactions.yaml stale pending.** If `_memory/transactions.yaml`
   exists and this build ships
   `superagent.tools.ingest.simplefin.mark_stale_pending`, apply it to the
   `transactions` list and write back only when it marked at least one
   row. When the helper is absent the step is skipped with a message.
   Checkpointed first.
7. Advance `workspace/.version` to `0.18.0`.

## Validate

`uv run python superagent/migrations/0.18.0/validate.py --workspace <path>`
runs all of these and exits 0 iff every check passes.

- [ ] No `### <title> -- <date>`, `## <date> -- <title>`, or other
      non-canonical dated entry header remains under `## Log` in any
      Domain / Project / Archive `history.md`.
- [ ] `_memory/model-context.yaml` `sessions` has at most 10 rows.
- [ ] Every `enabled: true` source in `_memory/data-sources.yaml` appears
      under `config.yaml` `data_sources_configured` (value `true`) and
      `preferences.ingestion_schedule`.
- [ ] `Outbox/README.md` exists.
- [ ] `workspace/.version` reads `0.18.0`.
- [ ] Re-running `migrate.py` reports "nothing to do" (idempotency).

## Revert

`uv run python superagent/migrations/0.18.0/revert.py --workspace <path>`
(`--dry-run` to preview) performs, in this order:

1. Restore every file under `_memory/_checkpoints/0.18.0/` to its original
   relative path (byte-for-byte), then remove the checkpoint folder so a
   later re-migration captures fresh originals. Edits made to those files
   AFTER the migration are lost by the restore -- re-apply them by hand if
   they matter.
2. Remove `Outbox/README.md` only if it is byte-identical to
   `superagent/templates/folder-readmes/Outbox.md` (a user-edited README is
   kept).
3. Restore `workspace/.version` to `0.17.2`.

`_memory/world.yaml` is derived and is left as rebuilt; the pre-0.18.0
tooling regenerates it on the next `world rebuild`.
