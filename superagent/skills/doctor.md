# Superagent doctor skill

> **Bulk reads** (`rules/subagents.md`): any lookup expected to pull more than
> ~20k tokens of raw tool results (~10k once the economy level resolves to `full`;
> multi-entity sweeps, whole email thread trees, long histories or archives) runs
> in a subagent (`Explore` read-only / `general-purpose` if it must write) that
> returns only the synthesis — named facts, quotes, `file:line` pointers — never
> raw dumps into the main transcript.


Six diagnostic passes. After each pass, ask the user `apply none / apply some / apply all`.

## 1. Stale domains

Find domains where:
- `_memory/domains-index.yaml.<domain>.status: active`
- AND no `history.md` entry in last 12 months
- AND zero open tasks for this domain in `todo.yaml`.

Surface table; offer `archive` (move folder to `Archive/<YYYY-MM>/Domains/<slug>/` AND set `domains-index.yaml.<domain>.status: archived`) per row.

## 2. Stale assets

Find assets where:
- `assets-index.yaml.<asset>.status: active`
- AND `last_updated` > 12 months ago
- AND no `history.md` reference in last 12 months.

Surface; offer `mark disposed` (asks for date / reason / proceeds) or `keep`.

## 3. Stale Resources/

Find files in `Domains/<domain>/Resources/` and `Projects/<slug>/Resources/` where mtime > 24 months ago AND no reference in any index.

Surface; offer `archive` (move to `Archive/<YYYY-MM>/_doctor-resources/`) or `keep`.

**Note**: `doctor` NEVER touches user-curated content under `Sources/` (nothing there is agent-managed; `Sources/Watchlist/` is a reserved name whose watcher refs are user-editable — `doctor` may report an evicted or unreachable watcher from `_memory/watchlist-state.yaml` but never deletes the ref; everything else is read-only per `contracts/sources.md` § 15.7). The strict pass for stale Sources is the user's job, surfaced via `monthly-review` § 7d as a candidate list, never auto-actioned.

## 4. Duplicates

For each of contacts, bills, subscriptions, appointments:

- Cluster by likely-same heuristics:
  - Contacts: same email OR same phone last-7 OR very similar names (Levenshtein < 3 on lower-cased name).
  - Bills: same payee + amount within ±5%.
  - Subscriptions: same provider.
  - Appointments: same provider + same date.
- Surface clusters; offer `merge into <id>` (canonical winner) or `keep separate` (with note).

## 5. Near-duplicate todos

Find tasks where `title` similarity > 80% AND status both open. Surface; offer `merge` (combine descriptions, take earlier created date, take stricter due date).

## 6. Simplification candidates

Find:
- Template-only files (a file in `Domains/<X>/info.md` whose body is identical to the template after substitution).
- Notes / file fragments that are < 100 chars.
- `Inbox/` files older than 14 days.
- `Tmp/` files older than 30 days.
- Empty subfolders.

Surface; offer `move to Archive/<YYYY-MM>/_doctor-deletions/` per row (reversible).

## 7. Broken cross-references

Validate:
- Every `bills.yaml.<bill>.account` exists in `accounts-index.yaml`.
- Every `bills.yaml.<bill>.pay_from_account` exists.
- Every `subscriptions.yaml.<sub>.pay_from_account` exists.
- Every `appointments.yaml.<appt>.provider` exists in `contacts.yaml`.
- Every `appointments.yaml.<appt>.asset` exists in `assets-index.yaml`.
- Every `assets-index.yaml.<asset>.domain` exists in `domains-index.yaml`.
- Every `documents-index.yaml.<doc>.path` exists on disk.

Surface broken references; offer `null out the field` or `repair` (interactive).

## 8. Expired documents

Find `documents-index.yaml` rows with `expires_at < today` AND `status: active`. Surface; offer `mark expired` (set `status: expired`) or `mark replaced` (asks for the new doc id).

## 9. Action signal drains

Find `_memory/action-signals.yaml` rows with `status: captured` older than 60 days. Surface; offer `process now` (delegates to `supertailor-review` for `target: tailor`, or to ad-hoc workspace action for `target: superagent`) or `decline` (with a reason).

## 10. Personal-signal review

Find `personal-signals.yaml` rows with `status: open` AND `surfaced_count > 5` AND `last_surfaced` > 90 days ago — these have been surfaced repeatedly without action. Offer `mark practicing` / `mark deferred` / `mark discarded`.

## 10b. World-graph freshness

If `_memory/world.yaml` exists and its mtime is older than 14 days, the graph
has drifted from the entity indexes it mirrors. Offer `rebuild now`
(`uv run python -m superagent.tools.world rebuild`) or `skip`. A graph stale
by more than 60 days is surfaced as a candidate for retirement instead —
"world.yaml has not been rebuilt in N weeks; rebuild it, or retire the
world-graph feature?".

## 10c. Signal-capture health

If `action-signals.yaml` + `personal-signals.yaml` together have near-zero
rows over a period where `user-queries.jsonl` is dense (an active user cannot
be correction-free for weeks), flag it as a **capture-adherence failure** —
the ambient capture + session-end sweep (`contracts/capture.md` § 7.2a) is
not running. Surface only; the fix is behavioral, not a file edit.

## 10d. Memory-routing check

Run `uv run python -m superagent.tools.memory_routing_check --since <last
doctor run>`. Exit 1 = remembered content found outside the sanctioned homes;
flag the reported files for migration per `rules/memory-routing.md` (migrate
in, then ask before deleting any outside-repo original).

## 10e. Project lifecycle drift

Run `uv run python -m superagent.tools.project_drift` and surface its
findings — per project: index status, days since the newest `history.md`
entry, and the drift hint (`stalled?` / `active?` / `archive-overdue`).
Surface only; status flips and archives stay user-approved (offer the
`projects` skill actions per row).

## 10f. Events-stream staleness

Run `uv run python -m superagent.tools.events_derive check`. Exit 1 = the
sources of truth (interaction-log.yaml / history.md files) have changed since
the last derivation. Offer `rebuild now`
(`uv run python -m superagent.tools.events_derive rebuild`) or `skip` —
the weekly-review § 8b derived-views step is the standing cadence.

**Pre-0.16.0 guard:** if `check` reports the stream has never been derived
AND partition rows are not flagged `legacy: true` (a pre-0.16.0
hand-authored partition), do NOT rebuild — run the `migrate` skill first.
A bare rebuild refuses in that state; `--allow-overwrite` would destroy the
hand-authored rows irrecoverably (the workspace is gitignored).

If the rebuild prints an `unmatched_headers` warning, surface the listed
`history.md` lines — those date-led H4 entries did not parse and are missing
from the timeline until their headers are fixed.

## 10g. Model-context hygiene

Read `_memory/model-context.yaml.sessions[]` (state-shape; per `AGENTS.md` § "Model context" and the template comment, it holds the **last 10** session summaries, **most recent first**). Report — do not auto-trim — when either holds:

- `len(sessions) > 10`.
- The `date` values (leading `YYYY-MM-DD`; a trailing qualifier such as `(topic)` is allowed) are not non-increasing top-to-bottom, i.e. rows were appended or interleaved out of order.

Surface the count and the first out-of-order pair, then offer `trim to newest 10 (re-sort newest-first)` or `skip`. Session summaries are user memory: trimming only happens on the user's explicit pick.
